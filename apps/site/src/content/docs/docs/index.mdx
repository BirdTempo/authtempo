**For:** a developer who adds authtempo to an app, or moves an app to authtempo.

**What it does:** this page lists the sections of the docs and the page to start each one.

## Before you start

- Know where your API runs and which database it has. [Choose your stack](/docs/start/) helps you choose.

## Sections

| Section | Start here | What it holds |
