**For:** a developer who must know what changed between two versions of authtempo.

**What it does:** this page lists each release of the authtempo packages. Every released package has the same version, so the changelog of `@authtempo/core` lists each release of the group.

- Read [Versioning policy](/docs/versioning/) for what each kind of version means.

## The feed

The feed [`/feed.xml`](/feed.xml) has one entry for each release of each package. A feed reader shows each new release.

## The record rule

A changelog is a record. `changeset version` writes each section from the changesets of the release. No later change edits a released section. A fault in an old section gets a correction in the next section. The release check `check-records` fails on an edit of a released section.

Until the first release, the plan index of the repo is the record of each change: `docs/superpowers/plans/README.md`. Each row names a plan, its spec sections, and the commit that merged it.
