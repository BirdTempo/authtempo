**For:** a developer whose browser app and API live on two origins.

**What it does:** the router answers the app's preflight, marks each answer for the app with credentialed CORS, and lands every sign-in on the app.

## Before you start

- A working setup from a [getting started tutorial](/docs/start/).
- The exact origin of the app, such as `https://app.example.net`, with no path and no trailing slash. It goes in `trustedOrigins` of [Top level](/docs/reference/config/#top-level).

## Steps

1. Set `appURL` to the origin of the app.
2. Add the same origin to `trustedOrigins`. Core refuses an `appURL` that is not `baseURL` or a trusted origin.
3. For an app on another site, set `cookie: { sameSite: "None" }`.
4. For an app on a sibling subdomain of the API, keep the default, `Lax`.

## How it behaves

- A trusted origin gets a 204 answer to its preflight. Any other origin gets 403.
- A POST with an `Origin` header that is not trusted answers 403 before any handler runs.
- A POST with no `Origin` header is a client that is not a browser, and passes.
- A form post, multipart, `text/plain`, or a post with no content type needs `Sec-Fetch-Site` to be `same-origin` or `none`. A JSON post with `Sec-Fetch-Site` set to `cross-site` or `same-site` needs a trusted `Origin`. Each refusal answers 403 [`origin_not_trusted`](/docs/reference/errors/#origin_not_trusted), and a request with no `Sec-Fetch-Site` passes.
- With `SameSite=None`, any site can make the browser send the cookie. The Origin rule is what refuses such a request.
- A `next` under `basePath` stays on `baseURL`. Every other `next` lands on `appURL`.
- The cookie names are `tempo_session` and `tempo_session_oauth`. A host on a sibling subdomain can set a cookie of the same name, so keep the API on its own registrable domain.

## If it fails

- [`origin_not_trusted`](/docs/reference/errors/#origin_not_trusted): the `Origin` header is not `baseURL` and not in `trustedOrigins`, or the browser marks a form post as not same-origin. Post JSON, or post the form from `baseURL`.
- The client answers `network` when the browser blocks an answer for an origin that is not trusted.
- `client.session()` answers `null` on another site when the cookie is `Lax`. Set `SameSite=None`.
