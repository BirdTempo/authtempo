This file is a record, and it is append-only. Do not edit an old line. A fault in a line gets a dated correction in a new line.

Each line names the version, the tagged commit, the `verify-published` line, and the `release-dry-run` line of the job `check` of `release.yml`.

This is the first release through the trusted publisher of GitHub Actions. Each of the 27 packages has provenance. The publish ran in attempt 3 of the run, and the registry times of the 27 versions run from 2026-11-18T02:06:53Z to 2026-11-18T02:11:51Z. Attempt 1 of the job `check` failed on one test of `adapter-mysql` (`claim-hold.test.ts`, claim beside an account delete), and attempt 2 passed with no change. The cause of that failure is open. The first run of the job `publish` failed on `@authtempo/core` with `ENEEDAUTH` and published nothing. The owner says the cause is the case of the organization name in the trusted publisher of `core` on npm. It read `birdtempo`, and GitHub names it `BirdTempo`. The owner changed it to `BirdTempo` between attempt 1 and attempt 3. Attempt 3 then published all 27 with no change of code. The npm form of a saved trusted publisher does not let a person edit the organization name. So the case of this name must match the GitHub name exactly when the trusted publisher is created.
