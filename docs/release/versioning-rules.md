# Versioning rules

The version rule of the authtempo packages. The versioning page of the site copies this rule, sentence by sentence. `apps/site/scripts/check-policy-pages.ts` holds that copy to the text below, so change both together.

This file is a record of the rule. A change to the rule is a decision of the owner, and it needs a dated line here.

2. 0.x until the first stable. The first release is `0.1.0`. In 0.x a break is a minor with a "Breaking:" line in its changeset, a feature is a minor, and a fix is a patch. The owner names `1.0.0` in a later decision.
