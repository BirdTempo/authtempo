Export `BETTER_AUTH_RANGE` and `inRange`. The range names the Better Auth versions that the package answers, `>=1.7.7 <1.8.0`. Better Auth below 1.7.7 has the advisory GHSA-965c-763c-88jm, so the range starts at 1.7.7. The package manifest holds the same range in `authtempo.betterAuth`.
